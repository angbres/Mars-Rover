# MEC 203 Mars Rover Design Project

## Overview

This project focused on the design and development of a sister rover concept based on NASA's Mars 2020 Perseverance mission. The goal was to build on the proven suspension and wheel design while developing and evaluating new gripper configurations for sample collection and analysis.

## Project Goals

- Develop a complete Mars rover CAD concept
- Maintain a reliable six-wheel rover platform
- Incorporate a robotic gripper for sample handling
- Evaluate mechanical design choices for reliability and functionality
- Produce a documented final design and project report

## Project Files

- **MEC203_Project_Report.pdf** — Final project report describing the rover concept and design goals
- **MEC203_Project_Files.zip** — CAD files and supporting project files used to develop the rover assembly

## Design Features

- Six-wheel rover configuration
- Suspension architecture based on the Perseverance rover platform
- Robotic gripper mechanism for sample handling
- Integrated rover chassis and onboard components
- Custom mechanical components modeled as part of the final assembly
